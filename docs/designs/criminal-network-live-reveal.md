## Problem Statement
Investigators drown in fragmented sources — FIR narratives, CDRs, bank/hawala transfers, social posts, criminal history — each in its own silo. Three cells (A-drug, B-arms, C-extortion) look unrelated in any single source. Only fused temporal + financial + communication signals reveal correlated burst week (days 58/61/64) and 4 bridges (X1 hawala, X2 weapons, X3 logistics, X4 corrupt contact) as one operation.

## What Makes This Cool
Live network reveal: dark canvas, graph draws itself, PLAY burst-week slider days 50-70 — days 58/61/64 detonate across all 3 cells simultaneously, bridges ignite gold. Click any node → why-flagged drawer with scores + source records. For investigators: from "3 cold cases" to "1 operation" in 90 seconds.

Schema sketch:
- Nodes: Person(id, name, role, cell), Phone, Account, Event(id, cell, day), Location, FIR, Post
- Edges: CALLED(day, dur, tower), TRANSACTED(amount, day, type), MENTIONED_IN(conf 0-1 per extractor), ASSOCIATED_WITH, BRIDGES_VIA
- Indexes: CONSTRAINT ON Person.id, INDEX ON Phone.number, INDEX ON Event(day) + pre-aggregated daily edge counts.
- T-shirt: S=Small (days), M=Medium (1-2 wks), L=Large. Approach A=S/Low, B=L/Med, C=M/Med on top of B.

4 golden queries: 1) betweenness → X1-X4 top, 2) Louvain → A/B/C, 3) burst co-activity 58/61/64, 4) structuring fan (C12 ← 18-25 cash <50k → C11 → X1/C1). /bridges endpoint covers bridge relevance separately.
Eval hygiene: ground-truth never enters pipeline; `score.py` runs separately on exports and never touches Neo4j. Fallback for community detection is label-propagation only.
Risk note: 4 bridges + Cell B 1.8x decoys may merge Louvain communities. Mitigation: eval gate pre-UI — run GDS on bridge-removed subgraph + filter BRIDGES_VIA edges with amount/count threshold before community detection; if decoys intrude top-6 betweenness, raise cross-cell weight and re-run spike test on synthetic CSVs now.

Detector definitions (MVP thresholds):
- Burst-sync: z = (count[d] - mean[d-6..d-1]) / std[d-6..d-1]; if std==0: z=0 unless count>2*mean then z=3; flag if z>2.0; correlated burst = ≥2 cells flag within 7-day span (covers 58/61/64).
- Structuring-fan: ≥10 cash txns <50000 INR to same receiver within 12 days + ≥2 consolidations ≥250k within 6 days → flag C12/C11.
- Bridge score: 0.6*norm_betweenness (GDS normalized 0-1, min-max over subgraph) + 0.4*(cross_cell_degree / max_cross_cell_degree); top-6 flagged (4 true bridges X1-X4 + allowance for 2 false-positives; success = X1-X4 all in top-6).

## API Contracts (MVP)
- GET /graph?day=INT → {nodes:[{id, label, cell, score}], edges:[{src, dst, kind, source, confidence}]}; 400 on bad day, strips ground_truth_flag.
- GET /bridges → [{id, name, role, bridge_score, cells:[A,B,C]}].
- GET /bursts → [{cell, day, zscore, window:[start,end]}].
- GET /why/:id → {id, top_signals, sources ≥2 rows}; 404 on unknown id.
- GET /ask?q=STRING → {template_id, cypher, params}; 400 on unknown template.
- All reads (/graph,/bridges,/bursts,/why,/ask) + loader runs append to audit.jsonl as {ts, user="demo-operator" constant (no auth MVP), query, result_ids}. No multi-user auth — explicit non-goal.
- Loader: `loader.py --clean` = delete + re-ingest idempotent; default incremental fails if nodes exist.
- quarantine.csv columns: row_no, source_file, reason, confidence. resolution.csv columns: master_id, merged_ids, method, confidence.

## Edge Cases
- Missing tower/day, conflicting timestamps → keep earliest + lowest confidence 0.3, log to quarantine.csv.
- Duplicate names / aliases → block by phone/account/cell prefix before fuzzy; RapidFuzz ≥85 + same phone/account exact → merge, log to resolution.csv, else separate confidence 0.5.
- Isolated noise nodes → filter degree<2 from reveal view but keep in DB.
- CSV schema drift → loader validates headers, fails fast with row number.
- ground_truth_flag stripping verified by test asserting flag column absent post-ingest; score.py separate.

### App shell + hierarchy (Pass 1)
- 56px top bar: left `OPERATION FUSION / Days 50-70 / SYNTHETIC DATA` badge, center `/ask` bar, right `Audit: ON • Offline` + `Quarantine: N rows` (clickable).
- Canvas fills viewport; right 400px push-drawer (canvas reflows, never overlay) with persistent 32px rail `Bridges (4) • Bursts (3) • Flags (n)` when closed.
- 72px timeline docked bottom, always visible. Primary during reveal = timeline; `/ask` dimmed to 60% until first burst; drawer queues `n new flags — pause to inspect`, never auto-opens during PLAY.
- Legend top-left over canvas, fixed tokens: A `#4C9AFF`, B `#AB68FF`, C `#FF7A45`; bridges gold `#FFC53D` fill + 3px stroke + 12px glow, z-index top, diamonds (all others circles); burst edge white 2.5px + 800ms pulse; conf<0.5 dashed 40% + `low` chip. Gold used nowhere else.

### Tokens (Pass 4/5, interim system — no DESIGN.md; run /design-consultation post-demo)

- Colors: bg `#0A0E14`, panel `#121826`, border `#1E293B`, text `#E6EDF3`, muted `#8B98AD`.
- 8pt grid, 16px gutters, 12px radius, 1px borders; drawer rows ≥48px; timeline 72px / 21 ticks; body ≥16px, contrast ≥4.5:1; rows-not-cards (no decorative card grids).

### PLAY + journey (Pass 3)
- Load: Day=50, cluster pills `CELL A — DRUG (n)` etc. + mission banner `3 cells look unrelated. Press PLAY 50→70 to test fusion.` (dismiss on PLAY).

- Detonation triple-cue: bridges scale 1.0→1.4 + glow, cross-cell edges 3px, ticks 58/61/64 persist gold.

### States (Pass 2)
- Boot skeleton (3 pulsing clusters + `Loading fused graph…`); day scrub edge-shimmer; `/why` drawer skeleton; PLAY disabled until boot.

- Bad day: shake slider + `Day must be 50-70`, canvas kept. 404 why: `Record quarantined — quarantine.csv Row [N]` + retry. Backend down: banner `Fusion offline — preloaded snapshot + backup video button` (one click).
